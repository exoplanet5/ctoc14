 第十四届全国空间轨道设计竞赛（CTOC14）题
                          目甲
       近地小行星防御多航天器遍历探测轨道设计与优化

          （太空系统运行与控制全国重点实验室）



                      1   题目背景
  小行星撞击是地球面临的现实潜在威胁之一，近年来，近地小行星（Near-Earth
Asteroid, NEA）防御已成为国际航天与天文领域高度关注的重大科学问题。需要指出
的是，在众多已被发现和编目的近地小行星中，相当一部分与地球的最小轨道交会距离
（MOID）很小、存在较高轨道交叉风险，而受限于地基观测手段，人类对这类潜在威胁
小行星的轨道、尺寸大小及物质成分等信息掌握仍不充分，如何提升对其认知与快速响
应能力已成为国际社会共同面临的挑战。为了在潜在威胁出现时具备有效的预警与应对
能力，派遣航天器对高威胁近地小行星开展飞越探测，精确测定其轨道、获取形貌尺寸
与材质特性等关键信息，是弥补地基观测不足、支撑行星防御决策的重要途径。
  为推动面向行星防御的深空探测体系的构建，本届竞赛题目甲设定为 “近地小行星
防御多航天器遍历探测轨道设计与优化”：设计多艘连续推力航天器的飞行轨迹，在固
定的任务周期内实现对 NEA 目标库中全部目标的飞越探测，并最小化任务总代价。


                      2   问题描述
  竞赛提供一个包含 300 颗候选 NEA 的目标库（见附件 MEA.txt）。参赛者需要：

 1. 确定任务航天器的数量 N （N ≥ 1），以及每艘航天器的发射时刻 tlaunch,i 与初始
   质量 m0,i （燃料携带量）；

 2. 确定每艘航天器从地球出发的双曲线超速方向；

 3. 在飞行过程中对每艘航天器施加连续小推力，设计其访问的小行星序列与推力方
   向时间历程；

 4. 在固定的任务周期内尽可能实现对目标库中全部 300 颗小行星的飞越探测；未全
   覆盖的方案仍可提交，但未覆盖目标将按第 5 节规则计入任务总代价。

                     3    坐标系与动力学模型

3.1    坐标系
      所有位置、速度均在日心黄道惯性坐标系（Heliocentric Ecliptic Inertial, HEI）下
描述：

  • 原点：太阳质心；

  • x-y 平面：J2000.0 黄道面；

  • x 轴：指向 J2000.0 春分点；

  • z 轴：指向黄道面法向，满足右手定则。

                                4       约束条件

4.1    发射约束
      任务开始时刻为

          t0 = 2030 年 1 月 1 日 0 时 0 分 0 秒（UTC） = MJD 62502.0.            (6)

      每艘航天器的发射时刻 tlaunch,i 需满足

                                     tlaunch,i ≥ t0 .                    (7)

      发射瞬时，航天器位置与地球位置相同：

                            r i (tlaunch,i ) = r ⊕ (tlaunch,i ).         (8)

      航天器相对于地球的双曲线超速大小不得超过

                  v∞ = ∥v i (tlaunch,i ) − v ⊕ (tlaunch,i )∥ ≤ 4 km/s,   (9)

方向可在空间中任意选择。

4.2    质量与燃料约束
      每艘航天器干质量固定为
                                  mdry = 600 kg.                  (10)

      第 i 艘航天器发射时携带燃料 mfuel,i ≥ 0，其初始质量为

                       m0,i = mdry + mfuel,i ≤ 2000 kg.           (11)

      初始质量（燃料携带量）为设计变量，直接计入任务代价（见第 5 节）。
      飞行过程中任意时刻质量不得低于干质量：

                                  mi (t) ≥ mdry .                 (12)


4.3    探测约束
      当航天器与小行星 j 的相对距离满足

                      dij (t) = ∥r i (t) − r j (t)∥ ≤ 1000 km     (13)

时，认为完成一次对该小行星的飞越探测。每个小行星仅首次被探测有效，重复探测不
重复计分但也不受惩罚。
      鼓励实现全部 300 颗小行星的全覆盖；每颗未被飞越探测的目标将在任务总代价中
额外增加 1 个单位（见第 5 节）。


4.4    其他约束
  • 不允许利用任何行星或小行星引力辅助变轨；

  • 推力方向与大小可自由选择，但需满足 0 ≤ T ≤ 0.5 N；

  • 航天器无需返回地球，完成探测任务后即可结束飞行。

刻 t 均须处于自 t0（2030-01-01 00:00 UTC，MJD 62502.0，即 t = 0）起 15 年之内，即

             0 ≤ t ≤ Tmax = 15 年 = 4.73364 × 108 s = 5478.75 天.   (14)

超出该时间窗口的飞越事件不计入覆盖。

6.1    填写规则
  1. 同一航天器的所有行必须按 Time 严格递增；第一行必须为 Event=0（发射），最
      后一行必须为 Event=4（结束）。

  2. Event=1 行为推力采样点，其 (Tx , Ty , Tz ) 给出该时刻的推力矢量。一段连续的
      Event=1 行序列构成一个推力弧；弧中间允许插入 Event=3 飞越行，不中断推力
      弧；推力弧之间由 Event=0/2/4 行分隔。

  3. 推力函数按如下规则定义：设某推力弧有 n 个采样点，时刻 t1 < · · · < tn ，当
      t ∈ [t1 , tn ] 时，推力的每个分量由采样值做 3 阶滑动窗口 Lagrange 插值确定——
      定位 t 所在区间 j（tj ≤ t ≤ tj+1 ），窗口起点 l = j − 1 并截断到 [0, n − 4]，用窗
      口内 4 个采样点插值；当 n < 4 时，改用全部 n 个采样点做 n − 1 阶插值。当 t
      在 [t1 , tn ] 之外时推力为零（即弧首、弧尾处推力瞬时开关）
                                        。飞越行时刻的推力同
      样按所在推力弧的插值确定。

  4. 推力弧内相邻 Event=1 行（忽略中间的 Event=3 行）的时间间隔不得小于 8640 s
      （0.1 天）；推力模长在任意时刻（包括相邻采样点之间）不得超过 0.5 N。

  5. Event=2 为滑行段节点（纯轨迹节点，推力为零），可用于分割较长的积分弧段；
      Event=3 为飞越探测事件行，记录飞越时刻的航天器状态，不改变推力状态。
7 校验说明                                                                         7


  6. 当 Event=0 时，位置必须与给定地球星历一致，速度必须满足 v∞ ≤ 4 km/s；
      Event=4 为任务结束行。Event=0/2/3/4 行的推力字段均填 (0, 0, 0)。

  7. 飞行过程中质量按 ṁ = −∥T (t)∥/(Isp g0 ) 连续变化，其中 T (t) 为插值推力；提交
      行中的质量须与该规律一致（校验容差 0.01 kg）。

  8. 所有浮点数建议使用双精度，行内字段以空格或制表符分隔；允许空行与以 # 开
      头的注释行，解析时忽略。由于动力学一致性容差为 1 km，位置、速度等字段建
      议至少输出 10 位有效数字（如 %.10e 或 %.17g），避免因输出舍入误差导致校验
      失败。

                               7   校验说明
      组委会将使用独立程序对提交文件进行校验，主要检查项如下：
7 校验说明                                                          8


 • 格式与结构：允许空行与以 # 开头的注释行；SC_ID 从 1 开始连续编号；每艘航
  天器首行必须为 Event=0（发射）、末行必须为 Event=4（结束）；同一航天器内
  Time 严格递增；推力弧内相邻采样行时间间隔不小于 8640 s；所有事件时刻满足
  0 ≤ t ≤ Tmax （式 (14)）。

 • 动力学一致性：从每一行状态出发，按式 (1) 积分到下一行时刻，其中推力 T (t) 按
  第 6 节定义的 3 阶滑动窗口 Lagrange 插值确定，质量按 ṁ = −∥T (t)∥/(Isp g0 ) 同
  步积分；位置误差不大于 1 km，速度误差不大于 1 m/s，质量误差不大于 0.01 kg。

 • 发射约束：发射时刻位置与地球星历位置误差不大于 1 km；速度满足 v∞ ≤ 4 km/s
  （校验容差 0.01 km/s）。

 • 推力约束：每个 Event=1 采样行的推力模长 ∥T ∥ ≤ 0.5 N；校验积分过程中对插
  值推力 ∥T (t)∥ 全程检查，任意时刻超过 0.5 N 即判违规；Event=0/2/3/4 行的推
  力字段必须为 (0, 0, 0)。

 • 探测约束：对每个 Event=3 行，计算该时刻航天器与 Asteroid_ID 列所指定小行
  星（编号须在 1–300 范围内）的距离，要求 d ≤ 1000 km；同一个小行星仅首次探
  测有效。未通过 Event=3 行申报的近距离经过不计入覆盖。

 • 质量约束：单艘航天器初始质量满足式 (11)（m0,i ≤ 2000 kg）；飞行中任意时刻
  m ≥ 600 kg。相邻行间质量由动力学一致性检查中的同步积分结果比对，误差不
  大于 0.01 kg。

 • 覆盖性与任务代价：统计在任务时间窗口内（t ≤ Tmax ）被探测到的小行星数量
  Ncovered ，未覆盖目标数 Nmiss = 300 − Ncovered ；按式 (15)–(16) 计算任务总代价 J
  （其中 m0,i 取各航天器 Event=0 行的质量列），J 越小排名越靠前。
